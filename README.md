# Конспект пари

PWA українською: після пари в Teams дає повну транскрипцію з таймкодами, пошук, позначки й конспект.

**Головне обмеження.** Під час дзвінка застосунок не записує звук на тому ж телефоні. Android і iOS не дають стороннім програмам записувати звук VoIP-дзвінка, а спільний доступ до мікрофона ламає його в Teams. Тому:

1. **Запис робить Teams** (Запис і транскрипція, мова — українська). Після пари завантажте .docx/.vtt або .mp4 сюди.
2. **Якщо Teams не записує:** увімкніть «Диктофон» у цьому застосунку на **другому** пристрої поруч із динаміком.
3. **Або вставте текст** вручну.

## Можливості

- Імпорт транскрипції Teams (.vtt, .docx: старий і новий формат) з іменами мовців і таймкодами.
- Аудіо або відео до ~2,5 год. ffmpeg.wasm читає файл шматками (WORKERFS), не вантажачи його в пам'ять цілком. Звук ріжеться на шматки по 10 хв (mono 16 kHz MP3 32 kbps), а розпізнає їх OpenAI `whisper-1` з `language=uk`.
- Відновлення після збою: кожен шматок зберігається в IndexedDB, тому обробка продовжується з першого незробленого.
- Пошук із підсвічуванням, позначки «важливо», «питання до мене» й «домашнє», а також плеєр: тап по таймкоду вмикає звук із цього місця.
- Конспект через Claude (`claude-opus-5-5` за замовчуванням) або OpenAI: зміст, терміни, домашнє завдання з дедлайнами, питання до студентів і згадки вашого імені.
- Експорт у .docx, .md і .txt, кнопка «Поділитися», резервна копія в JSON.
- Працює офлайн (Service Worker), має темну й світлу тему, встановлюється на головний екран.

## Запуск локально

```bash
python -m http.server 8765
```

Відкрийте http://localhost:8765. Збирати нічого не потрібно: бібліотеки вже лежать у `vendor/`.

## На телефоні

Для встановлення PWA й доступу до мікрофона потрібен **HTTPS**. Найпростіше викласти теку на GitHub Pages або Netlify (перетягніть теку на app.netlify.com/drop) і відкрити посилання в Chrome на Android або в Safari на iPhone, а тоді вибрати «Додати на головний екран».

## Ключі API

Ключі додаються в Налаштуваннях і зберігаються лише на пристрої (IndexedDB). Запити йдуть напряму з браузера в OpenAI чи Anthropic.

- OpenAI: розпізнавання аудіо (≈ $0.006/хв, тобто ≈ $0.72 за 2 год) і, за бажанням, конспект.
- Anthropic: конспект.

Імпорт транскрипції Teams, пошук, позначки й експорт працюють без ключів.

## Розробка

```bash
npm install        # бібліотеки для vendor/ і тестів
npm run vendor     # оновити vendor/ з node_modules
npm test           # тести розбору транскрипцій і Markdown
npm run fixtures   # згенерувати tests/fixtures/teams-sample.docx
```

| Файл | Що робить |
|---|---|
| `js/app.js` | маршрути й екрани |
| `js/parsers.js` | розбір .vtt, .docx, тексту й сегментів Whisper |
| `js/jobs.js` | обробка аудіо (конвеєр витяг → розпізнавання) і конспект |
| `js/ffmpeg.js` | ffmpeg.wasm: тривалість, нарізка шматків |
| `js/transcribe.js` | OpenAI Audio API, повтори, помилки українською |
| `js/summary.js` | конспект через Claude SDK або OpenAI, map-reduce для довгих текстів |
| `js/recorder.js` | диктофон сегментами по 10 хв, збереження кожні 15 с |
| `js/player.js` | відтворення по шматках |
| `js/export.js` | .docx, .md, .txt і «Поділитися» |
| `js/db.js` | IndexedDB |
